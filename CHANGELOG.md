# Changelog

Changes use the Keep a Changelog structure and semantic versions.

## [0.1.0] - initial export

### Added

- Organisation registries and deterministic rendered-manifest GitOps.
- Per-user namespaces, private login homes, OIDC roles and audited admission/exec controls.
- Account pacing and API gateway teams, budgets and attributed task keys.
- Entitled MCP/context integration with audience-bound pod identity.
- Optional factory, local lanes, runners, monitoring and operations modules.
- Adoption, threat model, runbooks, ADRs and contributor/agent adaptation guides.
- Sanitization and offline gates with explicit live VERIFY requirements.

### Security

- One-person interactive seats, API-only automation and no copied/backed-up logins.
- Default-deny, digest-pinned artifacts and named-secret configuration.
- Multi-user pilot and organisation security/legal approval before production adoption.
