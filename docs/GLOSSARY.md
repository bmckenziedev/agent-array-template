# Glossary

| Term | Meaning |
|---|---|
| Account | Seat, API credential scope or local pool with independent policy |
| Admission | Server-side resource/CONNECT validation before acceptance |
| API task | Bounded headless automation with user/team and API account attribution |
| Break-glass | Exceptional time-limited ticketed privileged access |
| Cap/reserve | Launch ceiling and protected allowance per usage window |
| Context source | Registered data delivered by push, MCP or feed |
| Data class | Classification that gates context and vendor routing |
| Discovered session | Observed existing process; discovery grants no control authority |
| Estate | Explicit team-associated repository allowlist with class/targets |
| Exec guard | CONNECT checks protecting exec/attach beyond RBAC |
| Factory | Approved bounded work with deterministic checks and reviewed results |
| Feed | Scheduled ingestion needing an implemented approved-source connector |
| Home node | Node holding a private user/tool login home |
| Input gate | Actor/session/action checks before process input |
| Kata | MicroVM runtime for guest isolation |
| Lease | Expiring account concurrency/start reservation |
| MCP | Model Context Protocol interface governed by registry/identity policy |
| Org directory | Rendered read-only user/team/account/entitlement data |
| Permission mode | CLI approval mode, subordinate to platform controls |
| Pool | Shared entitled API/local capacity, never pooled seat logins |
| PSA | Pod Security Admission namespace levels |
| Render scope | Global or entity-specific template expansion boundary |
| Rendered manifests | Generated desired state committed for GitOps |
| Seat | One person's interactive entitlement under an approved contract |
| Session | Tool process with actor/workspace/account/lifecycle |
| Spawned session | Authorised creation with recorded provenance |
| Stop governor | Turn/retry/time/spend/cancellation limits |
| Team | Registry/IdP entitlement, budget and fair-share boundary |
| Tombstone | Permanently reserved offboarded slug |
| VERIFY | Unproven behavior that blocks reliance on the capability |
| Virtual key | Limited attributed task gateway key with models/budget/expiry |
