# 0013: Rendered output layout for GitOps

Status: Accepted (design decision D3). Refines [0003](0003-rendered-manifests-gitops.md); 0003 remains in force.

## Context

Changes to users, teams and accounts alter access, quota and policy. Reviewers need to see those effects as a diff before they reach the cluster, and Argo CD must not run a privileged rendering plugin.

## Decision

The organisation commits `rendered/`, and Argo CD syncs only from it. Kubernetes manifests go under `rendered/global`; everything that is not a manifest goes under `rendered/files`. No Argo config-management plugin is used.

## Consequences

Every registry change produces a reviewable, reproducible diff, and `render.py --check` detects drift. Generated files enlarge commits and must be regenerated, never hand-edited. Non-manifest files must stay outside Argo manifest roots.

Integration refinement: per-entity manifests have their own roots, each generated by an ApplicationSet: `rendered/users/<slug>`, `rendered/teams/<team>` and `rendered/mcp/<server>`, alongside `rendered/global`. `rendered/files` holds non-manifest output, including plain Prometheus rule groups, Helm-only values such as the ARC module's and per-node preparation scripts. Consumer-native configuration and incomplete strategic-merge fragments are validated as exact assets and never applied as resources. Directory sources use `recurse: true` and `include: '*.yaml'`; Namespace objects carry `Prune=false,Delete=false`; StatefulSet Applications ignore replicas with `RespectIgnoreDifferences=true`. The output directory must carry `.rendered-by-aa-render` before stale files are removed.

## Alternatives considered

- Argo CD config-management plugin rendering in-cluster: rejected because it adds a privileged component and hides the effective diff.
- Helm releases per user or team: rejected because values diffs do not show effective policy.
- Uncommitted CI rendering: rejected because the reviewed state would differ from the applied state.

## What would make us revisit it

Rendered output becoming too large to review, or an Argo feature that shows rendered diffs before sync without a privileged plugin.
